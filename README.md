# Git Workshop Project

*Name:* Edwin Dominique Samson

*Project Title:* My Git Workshop Project

*Brief Description:*  
This is a simple HTML project created for the Git Workshop. The project demonstrates the basic use of Git for tracking changes and managing different versions of a project.

*Reflection:*  
The difference between git add and git commit is that git add stages the changes that I want to include in the next version, while git commit records those staged changes permanently in the Git repository with a message. In simple terms, git add prepares the changes and git commit saves them to the project history.
